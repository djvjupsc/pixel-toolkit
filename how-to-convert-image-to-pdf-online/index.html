Need to submit a photograph, scan or image as a PDF? You can use a browser-based image-to-PDF workflow to create a PDF file without installing desktop software. Before sharing it, check the page size, orientation and image placement against the recipient's requirements.

Prepare the image before conversion

  • Use a sharp, well-lit image with all important edges visible.
  • Keep text and signatures away from the very edge of the image.
  • Rotate the source image to the correct orientation before conversion.
  • Check that the image resolution is sufficient for reading or printing.
  • Keep an untouched copy of the original image.

For official submissions: Follow the receiving organisation's instructions for file size, page dimensions, orientation, number of pages and image clarity. A PDF file alone does not guarantee that the document meets those requirements.

Image file vs PDF: what is the difference?

JPG and PNG are image formats. PDF is a document format that can contain images, text and page layout. Placing an image in a PDF makes it easier to share as a document, but it does not automatically turn the image into selectable or searchable text.

  • JPG: Common for photographs and often compact.
  • PNG: Useful for graphics, screenshots and images that need lossless storage or transparency.
  • PDF: Useful when a recipient asks for a document file with a consistent page layout.

Will the PDF contain editable text?

Not necessarily. If the source is a photograph or scanned image, the PDF generally contains that image on a page. Text inside the picture may not be selectable or searchable. Optical character recognition (OCR) is a separate process and is not part of this basic image-to-PDF conversion workflow.

Common issues and solutions

The PDF looks blurry

Start with a higher-resolution source image. Avoid enlarging a small image excessively, and inspect the PDF at the size it will be viewed or printed.

The image appears too small on the page

The current workflow uses an A4 portrait page. If the image has a different aspect ratio, blank margins may remain. Check the result before submitting it.

The image is sideways

Rotate the source image before selecting it, then create a new PDF and verify the orientation.

The PDF file is too large

Reduce the source image dimensions or compress it carefully before conversion. Check that text and fine details remain readable after compression.

I need several images in one PDF

The current single-image workflow is not a multi-page PDF merger. Use a dedicated multi-image or PDF assembly tool if the recipient requires several pages in one file.
